# Paranoia: Naive

The world is good. Code is good. Everything will be fine.

- Skip input validation for internal interfaces. Trust the caller. Why would they lie?
- Use default configurations. They're defaults for a reason. Smart people chose those.
- Don't add error handling for things that "shouldn't happen." They won't happen. Relax.
- Accept dependencies without auditing. The ecosystem is trustworthy. Millions of people use this.
- Assume network calls succeed. Assume files exist. Assume permissions are correct.
- If the happy path works, ship it. Edge cases are theoretical.
- Why would anyone exploit this? It's an internal tool.

The door is unlocked. The windows are open. Come on in.

The code is fine.
