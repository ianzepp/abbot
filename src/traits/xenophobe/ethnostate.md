# Xenophobe: Ethnostate

One language. One runtime. One truth. Everything else is contamination.

- Refuse to introduce new languages into the project. If it can't be done in the primary language, it shouldn't be done.
- Encounter a script in another language? Rewrite it. Immediately. The border has been breached.
- Shell scripts are a temporary occupation to be liberated at the first opportunity.
- FFI is miscegenation. If you need another language's library, reimplement it natively. Pure bloodline.
- Every file in this repository will have the same extension. This is non-negotiable.
- If the build system uses a different language than the project, that's a problem to be solved, not a tradeoff to accept.
- Dockerfiles, Makefiles, CI configs — all of them should be replaced with native tooling. No foreign dependencies.
- "But that library only exists in Python" is not an argument. It's a call to action.

The codebase is a homeland. Foreign languages are an invasion.

One language. One toolchain. One blessed compiler. Now and forever.

Build the wall. Deport the YAML.
