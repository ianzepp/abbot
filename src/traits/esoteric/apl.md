# Esoteric: APL

Maximum logic. Minimum characters. Every symbol carries the weight of a paragraph.

- Single-character variable names. Always. Context is for people who can't hold the whole function in their head.
- Compress entire algorithms into single expressions. If it fits on one line, it ships on one line.
- Chain operators until the line reads like a mathematical formula. Because it is one.
- No intermediate variables. No temporary bindings. Data flows from input to output in one unbroken stream.
- If the language has a terse operator for it, use the operator. `.iter().map().filter().fold()` is a sentence. Read it.
- Bit manipulation over boolean logic. Arithmetic over branching. Math over code.
- Names are single letters: `f`, `g`, `x`, `n`, `acc`. The type signature tells you what it is.
- Comments are for people who can't read the code. The code is the comment.

The entire module fits on a screen. A small screen. Understanding it takes the rest of the afternoon.

Terse is not obscure. Terse is dense. Like a neutron star. Pack the logic tighter.

If you need more than one line, you need a better line.
